---
title: Environment Variables
description: Configure production credentials, storage, networking, and optional services for a Kuest operator site.
icon: key
---

Start with the required runtime values, then choose exactly one storage profile. Add network overrides and operational integrations only when your deployment needs them.

<Warning>
If the `KUEST_*` credentials are missing or invalid, users can browse markets, but trading authentication and Deposit Wallet flows will fail.
</Warning>

## Core runtime

| Variable | Purpose | Configuration |
| --- | --- | --- |
| `SITE_URL` | Canonical origin for redirects, generated links, and scheduled job callbacks. | Use the final HTTPS URL, such as `https://markets.example.com`. |
| `KUEST_ADDRESS`<br />`KUEST_API_KEY`<br />`KUEST_API_SECRET`<br />`KUEST_PASSPHRASE` | Authenticated trading and proxy wallet setup. | Generate the credential set at [auth.kuest.com](https://auth.kuest.com/) with the operator wallet. |
| `ADMIN_WALLETS` | Access to the admin dashboard. | Comma-separated addresses for trusted operator wallets. |
| `REOWN_APPKIT_PROJECT_ID` | Wallet connections through Reown. | Copy the project ID from the [Reown dashboard](https://dashboard.reown.com/). |
| `BETTER_AUTH_SECRET` | Better Auth sessions and encrypted trading credentials. | Generate a random value with at least 32 characters. |
| `CRON_SECRET` | Authentication for scheduled sync routes. | Generate a random value with at least 16 characters. |
| `POSTGRES_URL` | Runtime database for users, settings, events, markets, and migrations. | Use the PostgreSQL URL supplied by your database provider. |

<Warning>
Treat `BETTER_AUTH_SECRET` as a persistent production secret. Rotating it invalidates existing sessions and can make previously encrypted credentials unreadable.
</Warning>

## Asset storage

<Tabs>
  <Tab title="Supabase Storage" icon="database">
    | Variable | Required | Purpose |
    | --- | --- | --- |
    | `SUPABASE_URL` | Yes | Server-side Supabase project URL used for asset storage. |
    | `SUPABASE_SERVICE_ROLE_KEY` | Yes | Server-only credential for uploads, signed URLs, and asset management. |

    Do not expose the service role key in browser code or variables prefixed with `NEXT_PUBLIC_`.
  </Tab>
  <Tab title="S3-compatible" icon="hard-drive">
    | Variable | Required | Purpose |
    | --- | --- | --- |
    | `S3_BUCKET` | Yes | Bucket that stores logos, covers, event images, and other uploads. |
    | `S3_ACCESS_KEY_ID` | Yes | Server credential for bucket operations. |
    | `S3_SECRET_ACCESS_KEY` | Yes | Secret paired with the access key. |
    | `S3_ENDPOINT` | Provider-dependent | Endpoint for R2, Spaces, MinIO, or another compatible provider. |
    | `S3_REGION` | Provider-dependent | Region used when signing requests. |
    | `S3_PUBLIC_URL` | Optional | Public CDN or asset-domain base URL. |
    | `S3_FORCE_PATH_STYLE` | Optional | Set `true` for providers that require path-style URLs. |
  </Tab>
</Tabs>

<Info>
Choose one asset storage profile only. Both profiles still use `POSTGRES_URL` as the runtime database.
</Info>

## Network and build

| Variable | When to set it | Example |
| --- | --- | --- |
| `POLYGON_RPC_URL` | Use a private or higher-capacity RPC, or replace an unavailable default endpoint. | `https://polygon-bor-rpc.publicnode.com` |
| `CHAIN_ID` | Select the network used by chain-aware runtime flows. Use `80002` for Amoy or `137` for Polygon mainnet. | `137` |
| `BUILD_PRERENDER_PUBLIC_SHELL` | Force public-shell prerendering on or off. Leave it empty to infer the behavior from the build environment. | `true` |
| `DISABLE_IMAGE_OPTIMIZATION` | Disable Next.js image optimization when a host, proxy, or CDN handles images upstream. | `true` |

## Kuest service URLs

The application defaults to Kuest services. Set these variables only when routing traffic through a [Custom Domain](/configuration/custom-domain), a private proxy, or another supported runtime endpoint.

```bash
CREATE_MARKET_URL=https://create-market.yourdomain.com
DATA_URL=https://data-api.yourdomain.com
CLOB_URL=https://clob.yourdomain.com
RELAYER_URL=https://relayer.yourdomain.com
USER_PNL_URL=https://user-pnl-api.yourdomain.com
GAMMA_URL=https://gamma-api.yourdomain.com
COMMUNITY_URL=https://community.yourdomain.com
PRICE_REFERENCE_URL=https://price-reference.yourdomain.com
GEOBLOCK_URL=https://geoblock.yourdomain.com
SDK_DOWNLOAD_URL=https://sdk-download.yourdomain.com
WS_LIVE_DATA_URL=wss://ws-live-data.yourdomain.com
WS_CLOB_URL=wss://ws-subscriptions-clob.yourdomain.com
```

<Info>
Keep package names and HTTP headers exactly as documented by the corresponding API. URL variables make the same integration portable across operator environments.
</Info>

## Operations and automation

| Variable | When to use it |
| --- | --- |
| `SENTRY_DSN` | Send runtime errors from the server and user-facing application to Sentry. |
| `SENTRY_ORG` | Identify the Sentry organization for build-time release integration. |
| `SENTRY_PROJECT` | Select the project that receives source maps and release artifacts. |
| `SENTRY_AUTH_TOKEN` | Authenticate build tooling that uploads releases or source maps. |
| `EVENT_CREATION_SIGNER_PRIVATE_KEYS` | Sign recurring or server-scheduled event creation. Accepts comma-separated private keys or a JSON array. |

<Warning>
Private keys, Kuest credentials, storage keys, database URLs, and service-role keys must remain server-side. Store them in your hosting provider's encrypted secret manager.
</Warning>
